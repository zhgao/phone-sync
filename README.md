# PhoneSync — OPPO 手机照片同步到 Mac

Mac 上跑一个常驻服务，手机连同一个 WiFi 打开网页就能把照片传过来。
按 EXIF 拍摄时间自动分年月归档，重复照片自动跳过，传一半断了能续传。

照片存到：**`~/Pictures/来自OPPO手机/2024-03/IMG_1234.jpg`**

---

## 先看这里：三个你必须知道的限制

**1. MacBook 合盖 = 同步暂停。**
没有任何软件能绕过这个，Apple 硬件设计如此。实际体验是「到家开机/唤醒后自动补传」，不是秒级实时。
唤醒后重新打开手机页面点「开始同步」即可，Mac 端按内容哈希去重，**不会重复也不会丢**。

**2. 这不是微信小程序。**
微信小程序没有相册权限、没有后台常驻、读不到 WiFi 名称，做不到"自动同步"。
这个方案是**手机浏览器打开的网页 + 可添加到主屏**（PWA），体验和点开一个小程序一样，但零安装、不需要装 APK。

**3. 自动化的程度取决于手机侧。**
- 每次手动打开页面选图 → 立刻同步（最稳，100% 可用）
- 在 OPPO 的 Chrome 里授权一次相册目录 → 之后打开页面自动扫描新增的
- 真正的「到家自动跑」需要手机原生 App，见文末「想更自动」

## 快速开始

### 1. 启动服务

```bash
git clone https://github.com/zhgao/phone-sync.git
cd phone-sync
npm start
```

看到这段就成功了：

```
  PhoneSync Hub 已启动
  ─────────────────────────────────────────
  接收目录  /Users/你的用户名/Pictures/来自OPPO手机
  局域网    http://192.168.0.100:8848   (en0)
  WiFi      已连接（网络名已隐藏）
  ─────────────────────────────────────────
```

用 Finder 双击 `启动同步.command` 也行，效果一样。

### 2. 手机上打开

用手机浏览器（Chrome / 系统浏览器）访问 Mac 局域网地址：

```
http://192.168.0.100:8848
```

地址会随 WiFi 变化，启动日志里会显示当前 IP。

### 3. 装到手机主屏（可选但强烈建议）

在手机 Chrome 里：
- 点右上角「⋮」菜单
- 选「添加到主屏幕」/「安装应用」

之后桌面上会有一个独立图标，点开就是全屏的同步页面，跟小程序一样。

### 4. 开启开机自启

```bash
npm run install-launchagent
```

注册为 LaunchAgent，登录后自动启动、自动崩溃重启。

## 怎么用

| 操作 | 说明 |
|---|---|
| 选照片同步 | 点「选择照片/视频」，可多选。已同步过的会自动跳过 |
| 续传 | 传到一半断网/断电，重新点开始会从断点继续 |
| 去重 | 按 SHA-256 内容哈希判重，重复照片不会存两份 |
| 授权相册目录 | 授权后每次打开页面会自动扫描新增照片（需 Chrome） |
| 查看状态 | 顶部显示 Mac 在线状态、已存数量、占用空间 |

## 常用命令

```bash
# 启动 / 停止
npm start
lsof -ti tcp:8848 | xargs kill          # 手动停止

# 开机自启
npm run install-launchagent
npm run uninstall-launchagent

# 改端口 / 接收目录
$EDITOR ~/.phonesync/config.json        # 改完重启服务生效

# 跑自测
npm test

# 看日志
tail -f ~/.phonesync/launchd.out.log
```

## 真·自动同步（进阶）

现在的方案是"打开页面就同步"。要做到**到家连上 WiFi 自动跑**，只有两条路：

### 方案 A：Syncthing（推荐，免费开源）

Mac 和 OPPO 各装一个 Syncthing，点对点加密同步，不经过任何云。
OPPO 可以在应用市场或官网装包；连上家里 WiFi 就自动推，Mac 唤醒后自动补传。

这个方案的可靠性比网页方案高一个量级，因为它跑在系统后台，不受浏览器生命周期限制。

### 方案 B：OPPO 自带工具

ColorOS 自带的「手机助手」或云同步，在 Mac 上装对应 PC 端可以自动备份照片。
优点是不用折腾，缺点是照片要经过 OPPO 的服务器。

### 关于本方案

Mac 端服务可以继续留着，作为手动补传和总账本（它按 EXIF 归档、去重、生成缩略图，比系统相册更好翻）。
也可以只用 Syncthing，两套不冲突——Syncthing 传的文件也会被本服务索引到。

## 安全说明

- 只监听局域网，写操作仅接受 `192.168.x` / `10.x` / `172.16-31.x` 来源
- 上传接口在公网暴露时会被拒绝
- 照片不会离开你的局域网，不经过任何云服务
- 想关掉服务或改成手动启动，见上文「常用命令」

## 排错

| 现象 | 原因和处理 |
|---|---|
| 手机打不开页面 | 确认手机和 Mac 在同一 WiFi；检查 Mac 防火墙是否放行 8848 端口 |
| 显示「Mac 未响应」 | Mac 睡眠了，唤醒后页面自动重连 |
| WiFi 显示「网络名已隐藏」 | 正常，系统设置里隐藏了网络名，不影响同步 |
| 端口被占用 | `lsof -ti tcp:8848 \| xargs kill` |
| 照片没按年月分 | 照片没有 EXIF 拍摄时间，已回退到文件修改时间 |
| 视频传不动 | 大视频建议 WiFi 下传，4MB 分块支持断点续传 |
